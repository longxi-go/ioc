# ioc Gin adapter v0.2.0

Initial native Gin module for ioc v0.2.0, using Gin v1.12.0 and Go 1.27.

- Generate typed native handlers from Controller base paths, canonical HTTP
  annotations and seven verb shortcuts, including private and standalone handlers.
- Assemble active routes through a running ioc application with native Gin
  conflict checks. Controller instances are resolved per request by exact identity.
- Own request scope acquisition and bounded cancellation-independent cleanup in
  configurable middleware. Lookup failures return 503 and attach Gin errors;
  middleware failures report through the required OnError callback.
- Provide ginctl by composing root pkg/cli with codegen.Adapter. Generate, check,
  explain and graph retain the common flags and cancellation behavior.

Singleton and request controllers are supported. Prototype/custom acquisition,
HTTP library metadata, automatic binding/marshalling and middleware annotations
are outside this release. Applications own server shutdown, middleware order and
IoC lifecycle. Discard the Gin engine after route assembly errors.

The module requires `github.com/longxi-go/ioc@v0.2.0`. Install the generator with
`go install github.com/longxi-go/ioc/adaptors/gin/cmd/ginctl@v0.2.0` and add the
runtime dependency with `go get github.com/longxi-go/ioc/adaptors/gin@v0.2.0`.
