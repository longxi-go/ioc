# ioc v0.1.0

Introduce annotation-driven Go IoC with static code generation and managed
application lifecycles. Requires Go 1.27.0 or later. The module is
`github.com/longxi-go/ioc`; its compiler is `github.com/longxi-go/ioc/cmd/ioctl`.

- Generate same-package constructors, private field injection, typed queries and
  lifecycle calls from `+ioc:` comments, using Go source/type analysis and
  controller-tools markers. Runtime wiring uses no reflection or unsafe.
- Register immutable definitions in generated `init` functions. Application
  contexts own instances, singleton caches, explicit request/custom scopes and
  resource-prototype leases, with startup rollback and repeatable cleanup.
- Select dependencies by exposed type, name/alias, qualifiers and a unique
  primary. Support direct `T`, `Optional[T]`, `[]T`, and an outer `Provider`
  wrapping each, with generation/startup cycle and scope checks.
- Prepare a Nemo Environment before ordinary Bean construction. Inject the Gosr
  Environment interface, retain one startup snapshot for property/profile
  conditions, and support explicitly supplied Environment implementations.
- Evaluate structured `on-bean`, `on-missing-bean` and `on-property` conditions
  before constructing instances. Expose detached selection reports and resolve
  property-condition placeholders without reading configuration during generation.
- Apply named `depends-on` prerequisites before dependent construction and Init,
  including lazy targets, with explicit ownership and cleanup ordering.
- Deliver synchronous typed events through generated listeners, runtime
  `Ordered`/`PriorityOrdered` sorting and container lifecycle notifications.
- Publish library-owned adapters and metadata; compose application imports,
  dependency plans and typed query dispatch without manual runtime module lists.
- Provide `ioctl generate`, `check`, `explain` and `graph`. Format and type-check
  generated Go before writing output, and keep dependency source read-only.
- Publish English and Simplified Chinese reference documentation for annotations,
  configuration, injection, scopes, lifecycle, events and library composition.

Install the compiler with `go install github.com/longxi-go/ioc/cmd/ioctl@v0.1.0`
and add the module with `go get github.com/longxi-go/ioc@v0.1.0`. Use matching
compiler/runtime versions and commit generated output with application or library
source. Dynamic graph refresh, automatic configuration rebinding, Web adapters,
early-exposed circular objects and arbitrary method interception are outside
this release.
