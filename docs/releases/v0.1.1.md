# ioc v0.1.1

Add Gin integration examples and bilingual application development guides.
The IoC compiler and runtime APIs are unchanged from v0.1.0.

- Add a standalone Gin integration example covering generated dependency
  injection, request scopes and scope cleanup.
- Add a Coffee MVC application with SQLite persistence, server-rendered HTML
  pages and a REST API. Orders support creation, queries, updates, cancellation,
  deletion and preparation/pickup transitions, with optimistic version checks.
- Demonstrate Nemo configuration binding, generated Bean registration, interface
  and qualifier selection, lifecycle callbacks, typed events, and Bean, property
  and profile conditions in the Coffee application.
- Add English and Simplified Chinese manuals for both examples, including
  package boundaries, annotations, generation commands and HTTP integration.
- Expand the Pages navigation with an Examples section and document the
  application composition and request-scope lifecycle with diagrams.

The examples are separate Go modules with their own Make targets and tests.
HTTP routes are registered explicitly; HTTP mapping annotations and generated
route registration are not implemented in this release.

Install the compiler with `go install github.com/longxi-go/ioc/cmd/ioctl@v0.1.1`
and add the module with `go get github.com/longxi-go/ioc@v0.1.1`.
